# 🌐 Language Translation Tool

A web-based Language Translation Tool built with Python and Flask as part of the CodeAlpha AI Internship.

# Features
- Translate text between 15+ languages
- Auto language detection
- Copy translated text with one click
- Swap languages instantly
- Real-time character count
- Clean modern UI

# Tech Stack
- Python & Flask (Backend)
- MyMemory Translation API
- HTML, CSS, JavaScript (Frontend)

# How to Run
1. Clone the repo
2. Create a virtual environment: `python -m venv venv`
3. Activate it: `venv\Scripts\activate`
4. Install dependencies: `pip install flask requests python-dotenv`
5. Create a `.env` file with your email: `MYMEMORY_EMAIL=your@email.com`
6. Run: `python app.py`
7. Open: `http://127.0.0.1:5000`

# API Used
[MyMemory Translation API](https://mymemory.translated.net/)
